# Support

- **Questions and usage help:** open a GitHub Discussion or an issue at https://github.com/shahvatsalofficial/localsutra-ai/issues
- **Bugs:** use the bug report template; include `localsutra --version`, your OS, Node version and the exact command. Remove tokens, usernames and private paths first. Attach the `audit-report.md` if relevant.
- **Security problems:** do **not** open a public issue. See [SECURITY.md](SECURITY.md).
- **Response times:** this is a volunteer project. No SLA is offered or implied.
