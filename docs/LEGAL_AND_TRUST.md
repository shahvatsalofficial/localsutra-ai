## What ships
No third-party code (zero runtime and dev dependencies). No model weights, tokenizers or datasets. Fixtures are synthetic. Nothing is downloaded at install or run time. Reports use inline CSS only: no fonts, scripts, trackers or CDN calls.

## Privacy
No telemetry. No network access except loopback requests you ask for (`probe`, `infer`) and the optional `serve` bound to `127.0.0.1`. Reports contain hardware facts, model ids you supplied, timings and hashes. They can identify your machine: review before sharing. `localsutra privacy` prints the full data inventory. Redaction is heuristic.

## Claims discipline
No statement that a model will run, that a setup is private, secure or air-gapped, that a skill works natively in an IDE, or that a test passed without captured output. Adoption, user counts and testimonials are not claimed because they are not measured.

## Independent-audit stance
Every number in public docs is regenerated by `npm run proof` and tied to raw logs in `docs/proof/`. The audit is a reproducible self-assessment, not third-party certification. A third-party review is a roadmap item.
