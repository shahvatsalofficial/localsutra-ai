# Branding and naming

Name: **LocalSutra AI**. Tagline: *Know your hardware. Choose your model. Keep AI local.* Voice: calm, precise, no hype, no "guaranteed", no "100% private". "Sutra" (a concise rule or thread) signals short, rule-based guidance.

The name has **not** been trademark-cleared. The GitHub repository `shahvatsalofficial/localsutra-ai` and the npm package `localsutra-ai` were unused when checked on 2026-11-16. That is availability, not legal clearance.
