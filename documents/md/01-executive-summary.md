# Executive Summary

**LocalSutra AI** {{VERSION}} is an open-source (Apache-2.0), offline-first command-line tool that tells people whether their own computer can run a large language model, whether their local Ollama or llama.cpp server really is local, and how fast an installed model runs. Its promise: *Know your hardware. Choose your model. Keep AI local.*

## The problem
People who want to run AI locally for privacy, cost or learning face four guesses: will this model fit, what do I need to install, is my setup really private, and how fast will it be. Existing answers are scattered forum posts and calculators that present estimates as facts.

## The product
- A zero-dependency Node.js CLI (`localsutra`) with no API key, no account and no telemetry.
- **Hardware profile:** OS, CPU, RAM, free disk, WSL flag and NVIDIA GPU/VRAM when `nvidia-smi` exists. Everything else is reported *unknown*, never guessed.
- **Model-fit estimate:** a transparent memory formula with printed assumptions. It never promises a model will run.
- **Runtime probe and opt-in inference timing:** loopback only; prompt and output text are never stored.
- **Independent audit:** 37 adversarial checks plus samples and a not-tested list, delivered as **HTML, Markdown and JSON**.
- **25 portable Agent Skills** for Claude Code, Cursor, Codex, Gemini CLI, GitHub Copilot and OpenCode.

Every number is regenerated by `npm run proof` and linked to raw logs. See [Assurance and Evidence](13-assurance-and-evidence.html).

## What it deliberately does not do
It does not install runtimes, download models, rank models across unlike hardware, claim a setup is "private" or "air-gapped", or run live inference unless you ask. Live inference on a real model was **not run** for this release; the report says so.

## Risks and limits
Memory-fit numbers are heuristics. GPU detection covers NVIDIA only. IDE skill activation is not verified. No third-party security review has happened yet.

## Roadmap in one line
Real-runtime integration tests, more GPU vendors, consent-based install planning, signed audit capsules, external review. See [Roadmap and FAQ](11-roadmap-and-faq.html).
