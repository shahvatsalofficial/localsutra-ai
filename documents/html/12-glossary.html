Glossary

TermMeaning
Agent Skilla SKILL.md instruction file a coding agent may load; not a running process
Auditlocalsutra audit: adversarial checks plus samples and a not-tested list
Bits per weightstorage precision of model parameters (4-bit, 8-bit, 16-bit)
Cold / warm runfirst inference (includes model load) vs later runs
Evidence sealSHA-256 over the canonical report; integrity, not identity
Failure codestable machine-readable reason a probe failed
FitProofthis project's term for explaining estimate vs tested compatibility
GGUFmodel file format used by llama.cpp and Ollama
Heuristican estimate from stated assumptions, not a measurement
Headroommultiplier (1.35) added to weight size for runtime buffers; an assumption
KV cachememory for attention keys/values; grows with context length
Loopbackthe local-only network interface (127.0.0.1, ::1)
Not runa check that did not happen; never counted as a pass
Ollamaa local model runner exposing an HTTP API (third-party)
llama.cppa C/C++ inference engine with a server mode (third-party)
Offline boundaryvalidating that a client only talks to loopback; does not prove the runtime is offline
Quantizationstoring weights at lower precision to save memory
RSSresident set size: physical memory used by a process
Runtime-reportednumbers a local runtime supplied about itself
SSRFtricking software into requesting an unintended address
Synthetic benchmarka CPU loop used for timing; not model inference
Unknowncannot be determined here; not the same as absent
VRAMmemory on a graphics card
WSLWindows Subsystem for Linux; a virtualised environment whose figures may differ from the host
